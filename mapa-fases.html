  • Não substitui o plan.md. Os 27 campos de cada fase (escopo, testes, riscos, decisões, checkpoint de UX) continuam sendo a referência de execução. Este documento é um índice visual de consulta rápida.

  • Critério objetivo ≠ aprovação de UX. Passar nos testes de uma fase é condição necessária, nunca suficiente, para avançar.
  • Manutenção: atualize este arquivo (e o mapa-fases.md) no mesmo commit em que o status de uma fase muda no plan.md.
